Features

Everything a bug tracker needs,
nothing it doesn't

BugTracker is built around one idea: track bugs fast, locally, and let AI agents help when you want them to.

⊞

Kanban Board

Drag-and-drop columns with customisable statuses. Reorder cards, move between columns, and see your workflow at a glance.

✎

WYSIWYG Editor

Rich TipTap editor for issue descriptions. Tables, task lists, code blocks, images — all inline. Markdown import/export.

📁

File Previews

Attach images, PDFs, CSVs, and code files. Preview them inline or full-screen without leaving the app.

🔌

ETAPI Server

Embedded HTTP API for AI agents. Create, read, update, and search issues programmatically. Bearer token auth.

💾

Offline-First

All data lives in a local SQLite database. No server, no account, no internet required. Your data is yours.

🔍

Search & Filter

Full-text search across titles and descriptions. Filter by label, priority, assignee, and status.

◑

Themes

Light, Dark, Light Contrast, Dark Contrast, and Catppuccin presets. Custom accent colours and font sizing.

⌨

Keyboard-First

Navigate, create, edit, and transition issues without touching the mouse. Vim-style shortcuts optional.

Board

Drag, drop, done

A full Kanban board with customisable columns. Drag cards between statuses, reorder within columns, and see priorities at a glance.

  • Custom columns per workspace (Backlog → Done)
  • Priority indicators with colour coding
  • Card preview with title, labels, and assignee
  • Multiple workspaces with independent boards
board.gif — Drag-and-drop Kanban

Rich issue detail

Click any card to open the detail view. Full WYSIWYG editor, attachments, labels, priority, and activity log.

  • TipTap rich text with inline images
  • File attachments with preview tabs
  • Label and priority selectors
  • Activity timeline with timestamps
detail.gif — Issue detail view

ETAPI

Built for AI agents

An embedded HTTP API server runs inside the app. AI agents, scripts, and CI pipelines can create, query, and triage issues programmatically.

  • Bearer token authentication
  • Full CRUD for issues, labels, and columns
  • Full-text search endpoint
  • Toggle on/off at runtime — zero config
# Create an issue via ETAPI
POST /etapi/issues
{
  "title": "Login button unresponsive on Safari",
  "status": "Backlog",
  "priority": 3,
  "labels": ["bug", "frontend"]
}
GET

/etapi/issues

List and filter issues by status, label, priority, or assignee.

POST

/etapi/issues

Create a new issue with title, body, status, priority, and labels.

PATCH

/etapi/issues/:id/status

Transition an issue to a new column/status.

GET

/etapi/search

Full-text search across issue titles and bodies.

Install BugTracker

One command sets up the binary, config directory, and license — no manual download or unzip required.

🐧 Linux 🍎 macOS 🪟 WSL
curl -fsSL https://0cyborg.github.io/promo/bugtracker/install.sh | bash

Installs to ~/.local/bin, writes your license to ~/.config/bugtracker. Always inspect scripts you pipe into a shell — view the source first.
