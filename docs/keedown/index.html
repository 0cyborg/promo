A tour of Keedown

Seven things Keedown does, recorded in the app. Swipe, use the arrows, or pick a feature — click a demo to see it full size.

Write with a slash

Type / anywhere, filter by name and press Enter — no mouse needed.

  • Headings, lists, task lists and quotes
  • Code blocks with syntax highlighting
  • Tables, callouts, kanban boards and carousels
  • Images and attachments stored inside the note

Rich blocks, plain Markdown

Boards, callouts and tables render as you type — and every one of them is stored as plain text you can read anywhere.

  • Drag-and-drop kanban boards
  • Info, tip, warning and critical callouts
  • Tables with a row and column toolbar
  • Image and Markdown slides

Runbooks that run

Switch a code block on and run it with Ctrl+Shift+Enter or its ▶ button. Output streams in as it's produced.

  • Inline: every line is a command, its output right under it
  • Script: the whole block runs, output in a block below
  • Python, Go, Node and more through configurable runners
  • On this computer, the tab's SSH host, or a locked terminal

Nothing runs behind your back

Code blocks run only when their author switched them on, and a document from someone else shows you every command before the first one runs.

  • Trust a document, or run one command once
  • Trust covers the exact text — any change asks again
  • Hidden characters are shown before you decide
  • Sign your documents; teams can certify their authors

Every tab, one canvas away

Open the workspace and your tabs fan out as a tree of groups, with the current note beside it.

  • Nested groups, drag-and-drop and tab colours
  • Folders from disk linked in as groups
  • Filter by name, or search the text of every tab
  • Separate workspaces for work and personal notes

Pages that look the way you expect

See every page before it prints — on paper or to PDF.

  • A4, Letter or Legal, portrait or landscape
  • Headers and footers with title, date and page numbers
  • Fit wide content, wrap long code lines
  • Choose whether script output and highlights print

Four themes, every colour yours

Light, Dark, Light Contrast and Dark Contrast — the whole app follows instantly.

  • Override single colours on top of any theme
  • Text and code fonts and sizes
  • Terminal colour schemes and cursor style
  • Interface scale from 75% to 150%

Terminal & SSH

Connect anywhere, run anything

A full terminal is built in. Bind a tab to a remote host and the code you run from it executes there.

SSH key / cert

Standard SSH

Identity file or certificate auth to any OpenSSH-compatible host.

Password

Password auth

For hosts that don't accept keys.

GCloud IAP

Google Cloud IAP

Tunnel through Identity-Aware Proxy — no public IP needed.

AWS SSM

AWS Systems Manager

Session Manager access to EC2 without opening port 22.

Locked terminal

Your own session

Lock a tab to a terminal — even one you're already logged into — and its commands are typed there.
